# scUS：模态间的差异本身也能表示细胞

主文档：[关键结果与解释](MODALITY_DIFFERENCES_AS_CELL_REPRESENTATIONS_CN.md)。

本目录是2026-09-17的研究结果快照，包含正文直接引用的图、配套PDF、轻量结果表和报告，并保留负面结果与解释边界。

- `figures/`：原始PNG/PDF；未重新绘图。
- `tables/`：指标、逐对比效应、实例绘图数据与汇总。
- `reports/`：对应方法和限制；未发布的历史链接明确标注。
- `source_snapshot/`：正文引用的读出实现快照，仅用于溯源，不是独立可运行的软件发行包。
- [MANIFEST.csv](MANIFEST.csv)：源文件相对路径、源/发布SHA-256与文本转换记录。
- [OMITTED_REFERENCES.csv](OMITTED_REFERENCES.csv)：没有扩展打包的历史引用。
- [VALIDATION.json](VALIDATION.json)：体积、链接与发布卫生检查。

不包含原始H5AD/counts、完整embedding、checkpoint、训练缓存或凭据。保留的结果表可能含公开数据的sample或cell标识。没有把相关性解释为因果、RNA velocity或异常概率，也未宣称SOTA。
